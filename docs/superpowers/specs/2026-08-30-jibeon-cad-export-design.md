# 지번 기반 지적도/지형도/정사영상 CAD 내보내기 도구 — 설계 문서

## 배경 및 목적

지번(주소)을 입력하면 브이월드와 국토정보플랫폼에서 지적도·수치지형도·정사영상을 자동으로 검색·다운로드하고, 좌표계를 통일하고, 대상 필지를 강조 표시한 뒤 지정한 영역으로 잘라내어 도곽을 씌운 CAD(DXF)/이미지 파일로 내보내는 데스크톱 도구.

수작업으로 브이월드/국토정보플랫폼에서 자료를 하나씩 찾아 다운로드하고, CAD에서 좌표계를 맞추고 강조·클리핑·도곽 작업을 반복하는 시간을 줄이는 것이 목적.

## 범위

전체 7단계(지적도 검색·다운로드, 좌표계 선택, CAD 다운로드, 강조 표시, 영역 잘라내기, 도곽 씌우기, 지형도/정사영상 다운로드 및 좌표계 일치)를 한 번에 구현한다.

## 아키텍처

- **플랫폼**: Python 데스크톱 앱 (PySide6 UI)
- **핵심 라이브러리**:
  - `ezdxf` — DXF 생성/편집 (레이어, 폴리곤, 강조, 도곽)
  - `pyproj` — 좌표계 변환
  - `shapely` — 지오메트리 클리핑/버퍼/도곽 생성
  - `requests` — 브이월드/국토정보플랫폼 Open API 호출
  - `playwright` — API로 불가능한 다운로드(예: 지적도 CAD 원본)에 대한 웹 자동화 폴백
- **데이터 소스 우선순위**: 공식 Open API 우선 → 실패 또는 미지원 기능은 웹 자동화로 폴백
- **API 키**: 브이월드/국토정보플랫폼 API 키 미발급 상태. 개발 초기에는 목업 응답 데이터로 파이프라인을 구축·검증하고, 키 발급 후 교체한다.

## 데이터 흐름 (파이프라인)

1. **지번 입력 & 검색**: 사용자가 지번 하나를 텍스트로 입력 → 브이월드 API로 검색 → 매칭 필지의 주소/좌표를 화면에 표시해 확인받음
2. **지적도 다운로드**: 확인된 필지 기준으로 브이월드에서 지적도 원본(CAD/벡터) 다운로드. 사용자가 선택한 좌표계(기본값 GRS80 중부원점 EPSG:5186, 드롭다운으로 GRS80 서부/동부원점, UTM-K 등 변경 가능)로 수신
3. **지형도/정사영상 다운로드(선택)**: 사용자가 체크박스로 선택 시, 국토정보플랫폼에서 동일 지번에 일치하는 수치지형도와 정사영상을 다운로드
4. **좌표계 일치**: `pyproj`로 지적도/지형도/정사영상의 좌표계를 사용자가 선택한 좌표계로 통일 변환
5. **강조 표시**: 지적도 DXF에서 대상 필지 폴리곤을 별도 레이어(`HIGHLIGHT`)에 복제하고 다른 색상 적용
6. **내보내기 영역 잘라내기**: 대상 필지 중심 기준 버퍼 거리(기본값 제공, UI에서 수정 가능)로 사각형 클리핑 박스를 생성하고 `shapely`로 클리핑
7. **도곽 씌우기**: 원형/사각형(기본값 사각형, UI에서 선택 가능) 도곽 라인을 별도 레이어로 추가
8. **내보내기**: 지적도(DXF), 지형도(DXF), 정사영상(GeoTIFF + 월드파일)을 각각 별도 파일로 저장

## UI 구성

단일 화면, 단계형 레이아웃:

- 지번 입력창 + 검색 버튼
- 검색 결과(주소/좌표) 미리보기
- 좌표계 선택 드롭다운
- 지형도/정사영상 다운로드 체크박스
- 버퍼 거리 입력(기본값 있음), 도곽 형태 선택(사각형/원형)
- 실행 버튼 → 단계별(검색→다운로드→변환→강조→클리핑→도곽→내보내기) 진행 상태를 보여주는 로그/진행률 표시
- 결과 파일 경로 표시 + 폴더 열기 버튼
- 실행 취소/재시도 버튼

## 에러 처리

- 지번 검색 결과 없음 → 재입력 안내 메시지
- API 호출 실패 → 웹 자동화(Playwright)로 자동 폴백, 폴백도 실패하면 사용자에게 실패 단계와 원인을 명확히 표시
- 좌표계 변환 실패(좌표 범위 초과 등) → 원인을 표시하고 해당 단계에서 중단, 이전 단계 결과는 보존

## 테스트 전략

- **단위 테스트**: 좌표 변환 정확성(`pyproj` 결과 검증), DXF 레이어/강조 생성, 클리핑 지오메트리 계산, 도곽 생성 로직 — 각각 목업 데이터 기반 독립 테스트
- **통합 테스트**: 목업 API 응답으로 전체 파이프라인(검색→내보내기)이 끊김 없이 동작하는지 검증
- **실 API 테스트**: API 키 발급 후 실제 브이월드/국토정보플랫폼 호출로 소수 케이스 수동 검증
- **웹 자동화 폴백 안정성**: 사이트 구조 변경에 취약할 수 있으므로 실패 시 경고 로그를 남기고, 별도로 안정성을 모니터링

## 미해결/후속 검토 사항

- 브이월드/국토정보플랫폼 API 키 발급 절차 및 이용약관 확인 필요 (사용자가 직접 신청)
- 지적도 CAD 원본을 API로 받을 수 없을 경우, 웹 자동화 대상 페이지의 정확한 다운로드 흐름은 실제 사이트 확인 후 구체화
- 다중 지번 일괄 처리는 이번 범위에서 제외 (향후 확장 가능)
