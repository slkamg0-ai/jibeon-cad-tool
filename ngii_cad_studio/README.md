# 🗺️ NGII Map Studio (통합 현황지적지형도 CAD 추출기)

국토정보플랫폼(map.ngii.go.kr)의 **수치지형도(3D 등고선, 현황도로, 건물)**와 VWorld(브이월드)의 **실시간 지적도(대지경계선, 지번 라벨, 인접 필지)**를 결합하여, **완전체 현황지적지형도 CAD 도면(DXF), GeoJSON, Shapefile, 인터랙티브 웹 지도**를 원클릭으로 생성하는 통합 올인원 플랫폼입니다.

---

## ✨ 핵심 통합 기능

1. **실시간 지번/지적도 검색 및 클리핑 (VWorld API 연동)**
   - 지번 또는 도로명 주소(예: `고덕동 2728`, `역삼동 737`)를 입력하면 VWorld WFS 서버에서 지적도(`LP_PA_CBND_BUBUN`)를 실시간 호출
   - 검색 반경(50m, 100m, 200m, 300m, 500m / 사각형 또는 원형)으로 자동 버퍼 클리핑
   - **대상 필지(`HIGHLIGHT`)**: CAD 1번 빨간색 및 굵은 선으로 자동 강조
   - **인접 필지(`CADASTRAL`)**: CAD 7번 경계선으로 분리
   - **지번 라벨(`LABEL`)**: 한글 폰트(`malgun.ttf`)가 적용된 텍스트로 각 필지 중심에 정확히 자동 배치 (예: `2728대`, `2729-1전`)
   - **도곽선(`BORDER`)**: CAD 3번 녹색 점선 도곽선 생성

2. **국토정보플랫폼 3D 수치지형도 결합 & 레이어 선별**
   - 국토정보플랫폼 다운로드 압축파일(`.zip`), `.dxf`, `.shp` 드래그 앤 드롭 업로드
   - 674개 국토지리정보원 표준코드(A 교통, B 건물, C 시설, D 식생, E 수계, F 지형, G 경계, H 주기) 3단계 필터링
   - **3D 등고선(`F001`) 및 표고점(`F002`)의 실제 해발고도(Z값) 보존** ➔ SketchUp, Rhino, Civil 3D에서 즉시 3D 지형(TIN/Mesh) 형성

3. **단일 도면 완전체 출력 (현황지적도 CAD DXF)**
   - 지적선 + 지번 텍스트 + 3D 등고선 + 현황 건물이 **좌표 오차 없이 단 하나의 DXF 파일로 완벽 정렬되어 결합 출력**
   - 원클릭 포맷 선택: AutoCAD 3D DXF, GeoJSON, Shapefile 번들(ZIP), 독립형 HTML 뷰어

4. **인터랙티브 웹 지도 미리보기 (Leaflet)**
   - 국토교통부 표준 **VWorld 고해상도 항공위성 영상**, 일반지도, OpenStreetMap, 다크 모드 도면 배경 지원
   - 지도 위에서 지적 경계와 지형도 벡터가 위성사진 위에 실시간 중첩 렌더링

## 🚀 실행 방법

### 방법 1. 윈도우 원클릭 실행 (가장 쉬움)
프로젝트 폴더의 **`start.bat`** 파일을 더블 클릭합니다.
- 자동으로 필요한 라이브러리를 확인하고 웹 브라우저(`http://127.0.0.1:8000`)를 띄웁니다.

### 방법 2. 파이썬 명령어로 실행
```bash
py run.py
```

## 💡 사용 시나리오

1. **지적도만 필요할 때 (Jibeon CAD Tool 기능)**:
   - 상단 "1. 실시간 지번/지적도 검색"에 `고덕동 2728` 입력 ➔ [지적도 호출] ➔ [통합 DXF 다운로드] 클릭!
   - 100m 반경 지적도와 지번 텍스트가 담긴 캐드 도면 즉시 완성.

2. **수치지형도만 필요할 때 (NGII Map Studio 기능)**:
   - 국토정보플랫폼에서 받은 `.zip` 파일을 드래그 앤 드롭 ➔ 원하는 레이어(등고선, 도로, 건물) 선택 ➔ [다운로드] 클릭!

3. **지적도 + 수치지형도 통합이 필요할 때 (통합 기능)**:
   - 수치지형도 파일을 올리고, 지번 검색에 해당 대지 주소를 입력 ➔ [지적도 호출] 클릭!
   - 화면에 내 대지와 주변 지적선, 지번 라벨, 그리고 3D 등고선과 도로가 함께 오버레이됩니다.
   - [통합 도면 생성 & 다운로드]를 누르면 두 데이터가 합쳐진 완전체 현황지적지형도 DXF가 저장됩니다!
